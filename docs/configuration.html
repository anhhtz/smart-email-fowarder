Configuration Guide

Learn how to configure Smart Email Forwarder using the embedded Web Administration Console or command-line parameters.

Web Management UI

The application bundles a responsive web administration console directly inside the binary. Access it from any browser on the host machine at http://localhost:8080 (or http://<server-ip>:8080 from another intranet computer).

The console features six focused tabs:

  • Dashboard: Overview cards (Active/Paused state, total forwarded count, failure count), countdown to next poll cycle, immediate "Sync Now" button, and recent activity log.
  • Process Monitor: Process execution telemetry, PID/PPID, memory allocation (RSS, VmSize, VmPeak), CPU load averages, active threads, and subsystem health diagnostics.
  • Exchange Mailbox: Connection settings for querying the monitored Exchange mailbox over IMAP.
  • Forwarding Rules: Destination recipient emails, subject prefixes, polling frequency, and email header adjustments.
  • Exchange SMTP Relay: Connection parameters for relaying emails through Exchange out to Gmail.
  • Activity Logs: Real-time streaming log viewer displaying diagnostic messages, sync runs, and error stacktraces.

Exchange Mailbox (IMAP) Settings

These parameters govern how Smart Email Forwarder authenticates with and reads the corporate Exchange mailbox.

Field Example Description
Exchange Host / IP mail.corp.local or 192.168.10.5 Hostname or IP of the Microsoft Exchange Server.
Port 993 or 143 993 for direct TLS/SSL; 143 for STARTTLS or plaintext.
Encryption SSL/TLS Choose SSL/TLS (implicit), STARTTLS (opportunistic), or Plain.
Username CORP\user or user@corp.local Active Directory account or primary SMTP address of the monitored mailbox.
Password •••••••• Mailbox account password. Stored securely and masked across the UI and API.
Mailbox Folder INBOX The IMAP folder to poll for incoming messages (default: INBOX).
Mark as Read Enabled When checked, forwarded emails will have the \Seen flag set in Exchange.
Accept Self-Signed SSL Enabled Enables trusting corporate internal Root CA and self-signed certificates without errors.
Instant Test Exchange Connection

Before saving, click the "Test Exchange Connection" button. The application performs a live handshake, authenticates with Exchange, and reports back the round-trip latency and folder status.

Exchange SMTP Relay Settings

Emails are not dispatched directly to Google from the host server. Instead, they are routed through the internal Exchange Server's SMTP Receive Connector, which handles outbound internet delivery.

Field Example Description
Relay Host mail.corp.local Internal Exchange Server host or IP.
Port 25 (standard internal) or 587 Port 25 is standard for unauthenticated internal relays; 587 for STARTTLS.
From Email Address forwarder@corp.local The authenticated sender address authorized on the Exchange Receive Connector.
From Display Name Exchange Relay Friendly display name appearing in the recipient's email client.
Requires Authentication Disabled (Port 25) / Enabled Toggle if your Exchange Receive Connector requires SMTP AUTH credentials.
Exchange Receive Connector Tip

In Exchange Admin Center (EAC) → Mail Flow → Receive Connectors, ensure the host server's IP is added to the allowed IP ranges of your Internal Relay connector with the ExternallySecured or AnonymousUsers permission group enabled.

Forwarding Rules

Setting Default Description
Destination Addresses Required One or more target addresses (e.g. user@gmail.com, ops@gmail.com). Comma or newline separated.
Subject Prefix [Exchange-Fwd] Optional tag prepended to the forwarded email's subject line for Gmail filtering.
Polling Interval 1 (minute) Frequency in minutes for querying the Exchange mailbox. Range: 1 to 1440 minutes.
Forwarding Banner Enabled Injects a prominent summary banner at the top of the forwarded email body showing original sender, date, and recipients.
Preserve Reply-To Enabled Sets the original email sender as the Reply-To header so hitting "Reply" in Gmail replies directly to the original author.

CLI Arguments & Flags

When starting the binary from command line or service definition:

smart-email-forwarder [OPTIONS]
Argument Type Default Description
-p, --port Integer 8080 HTTP port for Web Console and REST API.
--host String 0.0.0.0 Interface IP to bind (127.0.0.1 for local only, 0.0.0.0 for network access).
--db Path data/forwarder.db Path to SQLite database file. Created automatically with parent folders.
--service Flag false Invoked by Windows Service Control Manager to signal Windows service execution mode.
-h, --help Flag - Displays help and usage manual.
-V, --version Flag - Displays software version string.
