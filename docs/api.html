REST API Reference

Smart Email Forwarder provides an internal REST API consumed by the web console and available for external orchestration or automated health checks.

Base URL & Authentication

Base URL: http://localhost:8080/api. When authentication is enabled, pass your token in the Authorization: Bearer <TOKEN> header, the X-Auth-Token: <TOKEN> header, or via the auth_token HTTP cookie.

1. Service Status & Telemetry

Returns general application status, sync counters, next sync countdown, and recent forwarding history.

2. Configuration Endpoints

GET /api/config

Fetches current Exchange IMAP, Forwarding, and SMTP Relay configurations (passwords masked).

POST /api/config/exchange

Updates Microsoft Exchange IMAP settings.

REQUEST BODY (JSON) 
{
  "host": "mail.company.local",
  "port": 993,
  "encryption": "SSL/TLS",
  "username": "CORP\\forwarder",
  "password": "SecretPassword123",
  "folder": "INBOX",
  "mark_read": true,
  "accept_invalid_certs": true
}

POST /api/config/forwarding

Updates forwarding recipients and rules.

REQUEST BODY (JSON) 
{
  "recipients": "user@gmail.com, ops@gmail.com",
  "subject_prefix": "[Exchange-Fwd] ",
  "poll_interval_mins": 1,
  "include_header_banner": true,
  "preserve_reply_to": true
}

POST /api/config/smtp

Updates internal Exchange SMTP relay settings.

REQUEST BODY (JSON) 
{
  "host": "mail.company.local",
  "port": 25,
  "from_email": "forwarder@company.local",
  "from_name": "Internal Exchange Relay",
  "require_auth": false,
  "username": "",
  "password": ""
}

3. Poller Controls & Connection Diagnostics

Method & Path Description
POST /api/sync Immediately wakes up the background poller worker to check for new messages.
POST /api/poller/pause Suspends scheduled background polling cycles.
POST /api/poller/resume Resumes scheduled background polling cycles.
POST /api/test/exchange Tests IMAP authentication and folder selection with configured parameters.
POST /api/test/smtp Sends a verification email through the SMTP relay to test delivery to Gmail.

4. Mailbox Explorer Endpoints

Method & Path Parameters Description
GET /api/mailbox/folders None Returns list of all folders in the monitored Exchange mailbox.
GET /api/mailbox/messages folder, page, page_size Paginated list of message envelope summaries in the specified folder.
GET /api/mailbox/message folder, uid Full parsed message details, HTML & text bodies, and attachments list.
GET /api/mailbox/attachment folder, uid, index Binary stream download of a specific attachment.
GET /api/mailbox/raw folder, uid Download raw RFC822 .eml file.
POST /api/mailbox/forward folder, uid, recipient (optional) Manually triggers forwarding of a specific message.
POST /api/mailbox/mark-read folder, uid, read (bool) Flags message as read or unread on the Exchange Server.
