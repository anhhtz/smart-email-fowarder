Mailbox Explorer

The Mailbox Explorer provides operators and administrators with direct, read-only inspection of remote Exchange folders, parsed MIME parts, attachment downloads, and manual forwarding controls.

Overview & Purpose

In production, administrators often need to verify why an email was forwarded, inspect an unread email that was skipped due to filtering, or re-forward a historical email to an auditor without logging into Outlook or an Exchange workstation.

The Mailbox Explorer interacts with the Exchange IMAP server on demand to offer an interactive email inspection console.

Core Capabilities

📁

Live Folder Hierarchy

Discovers and renders all mailbox folders (INBOX, Sent Items, Archive, Drafts, custom subfolders) with unread and total message counts.

🔍

Paginated Message Listing

Efficiently pages through hundreds of messages using IMAP UID ranges, displaying sender, subject, date, attachment count, and read/unread flags.

👁️

Safe HTML & Text Viewer

Renders sanitized rich HTML and plain text email bodies with complete metadata header inspection (From, To, Cc, Date, Message-ID).

📎

Attachment Inspector & Download

Enumerates all multipart attachments with their exact filename, MIME content-type, and file size. Allows one-click downloading of any attachment.

📜

Raw RFC822 EML Download

Exports the complete byte-for-byte unmodified .eml message payload for compliance audits or email header forensics.

🚀

Manual On-Demand Forwarding

Re-dispatches any selected message to the default destination list or specified override email addresses through the Exchange relay.

Operational Workflow

1. Navigating Folders

Selecting a folder on the left drawer requests GET /api/mailbox/messages?folder=INBOX&page=1. The forwarder establishes a short-lived IMAP session, fetches envelope headers, and populates the table without downloading heavy message bodies or attachments until explicitly clicked.

2. Inspecting Message Details

Clicking any message in the list opens the Message Details Modal. The modal displays:

  • Header Info: Original sender, recipient list, CC list, date, and unique Message-ID.
  • Body Tabs: View either the rendered HTML body or the plain-text alternative.
  • Attachment Strip: Badges for each attached file (PDF, XLSX, DOCX, ZIP, PNG). Clicking an attachment downloads it directly to your browser via /api/mailbox/attachment.

3. Manual Re-Forwarding

If an email needs to be sent to an additional colleague or re-sent after resolving an upstream relay issue, click "Forward Now". You can choose to:

  • Forward to the standard configured Gmail recipient list.
  • Specify a custom override destination email address.
Audit Logging

Every manual forward performed via Mailbox Explorer is logged in the SQLite logs table with the operator's IP address, message UID, and destination recipients.
