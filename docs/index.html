Smart Email Forwarder

A minimal, ultra-reliable, cross-platform email forwarding daemon written in Rust. Specifically engineered for offline and air-gapped enterprise environments such as Windows Server 2019 Standard and Linux Mint.

Enterprise Air-Gapped Ready

Smart Email Forwarder requires zero internet connectivity on the hosting server. It monitors an internal Microsoft Exchange mailbox via local IMAP, deduplicates incoming emails in an embedded SQLite engine, and forwards them to external destinations (e.g., Gmail) through the local Exchange SMTP relay.

Key Highlights

📦

100% Offline Single Binary

Compiles into a standalone .exe or ELF binary. Web UI assets and SQLite are compiled directly into the binary (rusqlite(bundled)). Zero external DLLs, Node.js, Python, or SQL servers required.

🛡️

Air-Gapped LAN Security

The host server communicates exclusively on the internal corporate network with Exchange. Supports internal enterprise CA root certificates and self-signed SSL/TLS.

📬

Full Email Fidelity

Preserves rich HTML, plain text, and all binary attachments (PDF, XLSX, ZIP, images). Preserves the original sender in Reply-To for effortless Gmail replying.

⚡

Zero Duplicate Forwarding

Tracks RFC822 Message-IDs in SQLite with indexed lookups to guarantee that server restarts or network interruptions never trigger duplicate forwards.

🔄

Unattended Background Service

Installs natively as a Windows Service on Windows Server 2019 (auto-boot, auto-recovery on failure in 5s) and as a systemd daemon on Linux Mint/Ubuntu.

📊

Embedded Admin Console

Modern responsive web console at http://localhost:8080 with real-time process telemetry (CPU, RSS memory, thread pool), live sync triggers, and Mailbox Explorer.

Quick Start

Follow these simple steps to compile and run Smart Email Forwarder on any development workstation or server:

Clone the repository and run immediately with Cargo:

# Run directly in development mode (starts on port 8080)
cargo run

# Run with verbose debug logging enabled
RUST_LOG=smart_email_forwarder=debug,tower_http=debug cargo run

# Run with custom port and database directory
cargo run -- --port 9000 --db data/forwarder.db

Once started, open your browser to http://localhost:8080.

Compile a standalone, highly optimized release binary:

# Build optimized release binary
cargo build --release

# Run standalone executable
./target/release/smart-email-forwarder --port 8080 --host 0.0.0.0

The resulting binary is completely self-contained. You can copy it to your target server without installing Rust or any runtime dependencies.

Smart Email Forwarder provides intuitive command-line options:

Flag Default Description
-p, --port <PORT> 8080 Port number for the embedded web console and REST API.
--host <HOST> 0.0.0.0 IP address to bind the web server (use 0.0.0.0 for intranet access).
--db <PATH> data/forwarder.db Path to SQLite database file. Created automatically if not present.
--service false Invoked by Windows Service Control Manager when running as a Windows Service.

Technology Stack

Component Technology Rationale
Core Language Rust (Edition 2021) Memory safety, high performance, zero runtime overhead, single static binary.
Async Runtime Tokio & Tracing High-throughput asynchronous I/O, scheduled periodic polling, non-blocking HTTP requests.
Web & API Server Axum & Tower HTTP Blazing-fast HTTP engine, embedded static asset delivery, resilient REST routing.
Database SQLite (rusqlite(bundled)) Embedded relational storage with WAL journaling; zero SQL server setup required.
MIME Parsing & Relay mail-parser & lettre Full RFC822/MIME parsing, multipart preservation, nested attachments, secure STARTTLS/SSL relay.
Frontend Admin UI Vanilla HTML5, CSS3, ES6 Embedded directly into the binary (include_str!); zero CDN calls, works 100% offline.
