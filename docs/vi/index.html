Smart Email Forwarder

Ứng dụng chuyển tiếp email chạy ngầm nhỏ gọn, tin cậy cao, đa nền tảng được viết bằng Rust. Thiết kế chuyên biệt cho môi trường doanh nghiệp cô lập / không có kết nối internet (air-gapped) như Windows Server 2019 Standard và Linux Mint.

Sẵn sàng 100% cho Môi trường Air-Gapped Doanh nghiệp

Smart Email Forwarder không yêu cầu bất kỳ kết nối internet nào trên máy chủ lưu trữ. Ứng dụng kết nối tới hòm thư Microsoft Exchange nội bộ qua IMAP trong mạng LAN, loại bỏ thư trùng lặp bằng SQLite nhúng, và chuyển tiếp ra các địa chỉ bên ngoài (như Gmail) thông qua SMTP Relay của chính Exchange nội bộ.

Điểm nổi bật cốt lõi

📦

Nhị phân duy nhất (100% Offline)

Biên dịch thành một tệp thực thi độc lập (.exe trên Windows hoặc ELF trên Linux). Giao diện Web và SQLite được nhúng trực tiếp vào binary lúc biên dịch (rusqlite(bundled)). Không cần cài đặt Node.js, Python, hay SQL Server.

🛡️

Bảo mật mạng LAN nội bộ

Máy chủ lưu trữ chỉ giao tiếp trong mạng nội bộ với máy chủ Exchange. Hỗ trợ đầy đủ các chứng chỉ số nội bộ (Internal CA) và chứng chỉ SSL/TLS tự ký mà không gặp trở ngại.

📬

Bảo toàn vẹn nguyên cấu trúc Email

Giữ nguyên định dạng Rich HTML, Plain Text, hình ảnh nội dòng và tất cả tệp đính kèm (PDF, Word, Excel, ZIP...). Giữ nguyên người gửi gốc trong tiêu đề Reply-To để trả lời trên Gmail tự nhiên.

⚡

Chống trùng lặp tuyệt đối

Lưu vết định danh RFC822 Message-ID trong SQLite với chỉ mục B-tree. Đảm bảo dù máy chủ khởi động lại đột ngột hay mất mạng tạm thời cũng không bao giờ gửi trùng email.

🔄

Dịch vụ chạy ngầm tự động

Cài đặt trực tiếp thành dịch vụ Windows Service trên Windows Server 2019 (tự khởi động khi bật máy, tự phục hồi sau 5s khi gặp sự cố) hoặc dịch vụ systemd trên Linux.

📊

Bảng điều khiển Web hiện đại

Trang quản trị tại http://localhost:8080 với màn hình giám sát tiến trình thời gian thực (CPU, RAM RSS, luồng OS), kiểm tra kết nối tức thời và trình duyệt hòm thư trực tiếp.

Mô hình kiến trúc tổng quan

Hình 1.1: Mô hình mạng air-gapped. Ứng dụng chỉ giao tiếp trực tiếp với máy chủ Exchange trong mạng nội bộ.

Bắt đầu nhanh

Các bước khởi chạy Smart Email Forwarder trên máy trạm phát triển hoặc máy chủ thực tế:

Tải mã nguồn và chạy ngay bằng công cụ Cargo của Rust:

# Khởi chạy ở chế độ phát triển (mặc định mở cổng 8080)
cargo run

# Khởi chạy kèm log chi tiết (debug level)
RUST_LOG=smart_email_forwarder=debug,tower_http=debug cargo run

# Tùy chỉnh cổng mạng và đường dẫn cơ sở dữ liệu
cargo run -- --port 9000 --db data/forwarder.db

Sau khi khởi chạy thành công, mở trình duyệt tới địa chỉ http://localhost:8080.

Biên dịch tệp nhị phân release siêu tối ưu, sẵn sàng đóng gói triển khai:

# Biên dịch bản release
cargo build --release

# Chạy tệp thực thi độc lập
./target/release/smart-email-forwarder --port 8080 --host 0.0.0.0

Tệp nhị phân sinh ra hoàn toàn độc lập, bạn chỉ cần copy duy nhất tệp này sang máy chủ đích mà không cần cài đặt Rust hay bất kỳ thư viện ngoài nào.

Các tham số dòng lệnh thông dụng:

Tùy chọn Mặc định Ý nghĩa
-p, --port <PORT> 8080 Cổng mạng mở cho giao diện quản trị Web và REST API.
--host <HOST> 0.0.0.0 Địa chỉ IP lắng nghe (dùng 0.0.0.0 để cho phép máy khác trong mạng truy cập).
--db <PATH> data/forwarder.db Đường dẫn tới tệp cơ sở dữ liệu SQLite. Tự động khởi tạo nếu chưa có.
--service false Được gọi tự động bởi Service Control Manager khi chạy dưới dạng Windows Service.
