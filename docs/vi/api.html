Tài liệu REST API

Smart Email Forwarder cung cấp hệ thống REST API nội bộ phục vụ giao diện Web và hỗ trợ tích hợp với các công cụ tự động hóa, giám sát hạ tầng ngoài.

Đường dẫn Cơ sở (Base URL) & Xác thực

Base URL: http://localhost:8080/api. Khi tính năng xác thực được kích hoạt, bạn truyền token qua tiêu đề Authorization: Bearer <TOKEN>, tiêu đề X-Auth-Token: <TOKEN>, hoặc qua HTTP cookie auth_token.

2. Các Endpoint Cấu hình

GET /api/config

Lấy toàn bộ thông số cấu hình hiện tại của Exchange IMAP, Forwarding và SMTP Relay (mật khẩu đã được che giấu an toàn).

POST /api/config/exchange

Cập nhật thiết lập IMAP máy chủ Microsoft Exchange.

THÂN YÊU CẦU (JSON) 
{
  "host": "mail.company.local",
  "port": 993,
  "encryption": "SSL/TLS",
  "username": "CORP\\forwarder",
  "password": "SecretPassword123",
  "folder": "INBOX",
  "mark_read": true,
  "accept_invalid_certs": true
}

POST /api/config/forwarding

Cập nhật danh sách người nhận và quy tắc chuyển tiếp.

THÂN YÊU CẦU (JSON) 
{
  "recipients": "user@gmail.com, ops@gmail.com",
  "subject_prefix": "[Exchange-Fwd] ",
  "poll_interval_mins": 1,
  "include_header_banner": true,
  "preserve_reply_to": true
}

POST /api/config/smtp

Cập nhật cấu hình Exchange SMTP Relay nội bộ.

THÂN YÊU CẦU (JSON) 
{
  "host": "mail.company.local",
  "port": 25,
  "from_email": "forwarder@company.local",
  "from_name": "Internal Exchange Relay",
  "require_auth": false,
  "username": "",
  "password": ""
}

3. Điều khiển Poller & Kiểm tra Kết nối

Phương thức & Đường dẫn Chức năng
POST /api/sync Kích hoạt tiến trình quét ngầm kiểm tra hòm thư ngay tức thì.
POST /api/poller/pause Tạm ngưng chu kỳ quét tự động định kỳ.
POST /api/poller/resume Khôi phục chu kỳ quét tự động định kỳ.
POST /api/test/exchange Kiểm tra kết nối và quyền đăng nhập IMAP tới máy chủ Exchange.
POST /api/test/smtp Gửi một email thử nghiệm qua SMTP Relay để xác minh khả năng gửi tới Gmail.

4. Endpoint Trình khám phá Hộp thư

Phương thức & Đường dẫn Tham số Mô tả chức năng
GET /api/mailbox/folders Không có Trả về danh sách tất cả các thư mục trong hòm thư Exchange.
GET /api/mailbox/messages folder, page, page_size Danh sách phân trang tiêu đề email trong thư mục đã chọn.
GET /api/mailbox/message folder, uid Xem chi tiết nội dung email (HTML, Plain Text) và metadata tệp đính kèm.
GET /api/mailbox/attachment folder, uid, index Tải về luồng nhị phân của tệp đính kèm tương ứng.
GET /api/mailbox/raw folder, uid Tải về tệp .eml RFC822 nguyên bản chưa qua chỉnh sửa.
POST /api/mailbox/forward folder, uid, recipient (tùy chọn) Kích hoạt gửi lại thủ công một email cụ thể.
POST /api/mailbox/mark-read folder, uid, read (bool) Đánh dấu email là đã đọc hoặc chưa đọc trên máy chủ Exchange.
