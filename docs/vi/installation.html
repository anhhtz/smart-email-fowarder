Cài đặt & Triển khai

Smart Email Forwarder được thiết kế để triển khai nhanh chóng trong các môi trường doanh nghiệp air-gapped: không cần cài thêm trình quản lý gói, không cài đặt runtime môi trường và không phụ thuộc thư viện ngoài.

Triển khai trên Windows Server 2019 Standard

Trong các trung tâm dữ liệu cô lập, máy chủ Windows Server 2019 Standard thường bị ngắt hoàn toàn kết nối Internet. Việc triển khai chỉ đơn giản là sao chép tệp thực thi duy nhất và đăng ký dịch vụ với công cụ sc.exe tích hợp sẵn của Windows.

Bước 1: Sao chép Tệp nhị phân & Kịch bản

  1. Biên dịch smart-email-forwarder.exe trên máy trạm xây dựng hoặc tải từ trang Release.
  2. Tạo một thư mục chuyên dụng trên máy chủ đích, ví dụ: C:\SmartEmailForwarder.
  3. Sao chép tệp thực thi và thư mục deploy\windows\ vào đó:
C:\SmartEmailForwarder\
├── smart-email-forwarder.exe
├── data\
└── deploy\
    └── windows\
        ├── install_service.bat
        ├── uninstall_service.bat
        └── run.bat

Bước 2: Cài đặt Dịch vụ Tự động

Nhấp chuột phải vào Command Prompt hoặc PowerShell, chọn "Run as administrator" và chạy lệnh:

CMD (ADMINISTRATOR) 
cd C:\SmartEmailForwarder
deploy\windows\install_service.bat
install_service.bat Thực hiện những gì?

Kịch bản kiểm tra quyền Administrator, đăng ký dịch vụ SmartEmailForwarder qua sc.exe, đặt chế độ khởi động Automatic (chạy ngay khi bật máy trước khi bất kỳ ai đăng nhập), cấu hình Tự phục hồi sau sự cố (tự khởi động lại sau 5 giây nếu tiến trình dừng đột ngột), và bật dịch vụ ngay tức thì.

Cách 2: Đăng ký Dịch vụ Thủ công qua sc.exe

Nếu bạn muốn kiểm soát chính xác từng câu lệnh của Windows Service Control Manager:

LỆNH ĐĂNG KÝ DỊCH VỤ THỦ CÔNG 
:: 1. Tạo dịch vụ Windows Service
sc.exe create "SmartEmailForwarder" binPath= "\"C:\SmartEmailForwarder\smart-email-forwarder.exe\" --service" start= auto DisplayName= "Smart Email Forwarder"

:: 2. Đặt mô tả cho dịch vụ
sc.exe description "SmartEmailForwarder" "Kiem tra mailbox MS Exchange va chuyen tiep email sang Gmail qua internal Exchange relay."

:: 3. Cấu hình tự khởi động lại khi crash (restart sau 5 giây)
sc.exe failure "SmartEmailForwarder" reset= 86400 actions= restart/5000/restart/5000/restart/5000

:: 4. Khởi động dịch vụ
sc.exe start "SmartEmailForwarder"

Cấu hình Tường lửa Windows Firewall (Tùy chọn)

Để mở quyền truy cập giao diện quản trị Web từ các máy tính khác trong mạng nội bộ công ty:

POWERSHELL (ADMINISTRATOR) 
New-NetFirewallRule -Name "SmartEmailForwarder_WebUI" `
  -DisplayName "Smart Email Forwarder Web Console (Port 8080)" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 8080 `
  -Action Allow

Triển khai trên Linux Mint & Ubuntu

Trên môi trường Linux, ứng dụng được quản lý như một dịch vụ systemd chuẩn của hệ điều hành.

Bước 1: Cài đặt Tệp nhị phân

BASH 
# Tạo thư mục ứng dụng
sudo mkdir -p /opt/smart-email-forwarder/data

# Sao chép tệp nhị phân và cấp quyền thực thi
sudo cp target/release/smart-email-forwarder /opt/smart-email-forwarder/
sudo chmod +x /opt/smart-email-forwarder/smart-email-forwarder

Bước 2: Cấu hình Tập tin Dịch vụ Systemd

Sao chép tệp unit mẫu từ deploy/linux/email-forwarder.service vào thư mục dịch vụ của hệ thống:

/etc/systemd/system/email-forwarder.service 
[Unit]
Description=Smart Email Forwarder Service
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/smart-email-forwarder
ExecStart=/opt/smart-email-forwarder/smart-email-forwarder --port 8080 --host 0.0.0.0 --db /opt/smart-email-forwarder/data/forwarder.db
Restart=always
RestartSec=5s
LimitNOFILE=65536
Environment=RUST_LOG=smart_email_forwarder=info,tower_http=info

[Install]
WantedBy=multi-user.target

Bước 3: Kích hoạt & Chạy Dịch vụ

BASH 
# Nạp lại cấu hình dịch vụ
sudo systemctl daemon-reload

# Kích hoạt tự chạy khi khởi động và bật dịch vụ ngay
sudo systemctl enable --now email-forwarder.service

# Kiểm tra trạng thái đang chạy
sudo systemctl status email-forwarder.service

# Xem luồng log thời gian thực
journalctl -u email-forwarder.service -f

Biên dịch từ Mã nguồn

Dành cho các kỹ sư muốn tự biên dịch trên máy trạm trước khi chuyển giao vào phòng máy:

Yêu cầu tiên quyết

  • Bộ công cụ Rust: Phiên bản 1.75 trở lên (cài đặt qua rustup).
  • Trình biên dịch C: gcc/clang trên Linux, hoặc Visual Studio Build Tools (C++) trên Windows (để biên dịch SQLite nhúng).
  • Thư viện OpenSSL: Header phát triển OpenSSL (hoặc SChannel trên Windows).

Đóng gói Offline cho Máy chủ Air-Gapped (Cargo Vendor)

Nếu máy trạm phát triển có mạng trước khi ngắt kết nối vào môi trường cô lập, bạn có thể tải trước toàn bộ thư viện phụ thuộc:

BASH 
# Tải toàn bộ thư viện dependencies về thư mục vendor/
cargo vendor

# Biên dịch hoàn toàn offline mà không cần kết nối internet
cargo build --release --frozen --offline

Biên dịch chéo (Cross-Compile) cho Windows từ Linux

# Thêm kiến trúc đích cho Windows
rustup target add x86_64-pc-windows-gnu

# Cài đặt trình biên dịch mingw
sudo apt-get install mingw-w64

# Biên dịch ra file thực thi .exe
cargo build --release --target x86_64-pc-windows-gnu
